# nextdns-go documentation

Reference material for `nextdns-go` consumers and maintainers. The SDK's package-level API documentation lives on [pkg.go.dev](https://pkg.go.dev/github.com/jacaudi/nextdns-go/nextdns); this directory carries the supporting prose.

## Contents

- [migrating.md](./migrating.md) — v0.x → v1.0.0 migration guide.
- [workflow.md](./workflow.md) — release workflow, conventional-commit conventions, downstream consumption, troubleshooting.

## Untracked sub-directories

These are gitignored and used by Claude Code agent workflows:

- `docs/plans/` — design and implementation plans for in-flight work.
- `docs/review/` — code-review notes.
- `docs/prompts/` — session handoff artifacts.

If you arrive here as a contributor and don't see those directories, that's expected — they're per-clone scratch space, not part of the published package.
